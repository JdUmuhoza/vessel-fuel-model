# Experiment stages of the paper

Each script below writes one folder of `results/revision_final/` with the same number. The
numbers follow the order in which `python -m reproduce.reproduce --full --yes` runs them
(`reproduce/stages.json`); later stages read the folders of earlier ones. Run a single stage
with `python -m experiments.revision.<script name without .py>`.

| Stage | Results folder | What it produces in the paper | Original name |
|---|---|---|---|
| `s01_full_data_602020` | `01_full_data_602020` | Chronological 60/20/20 protocol, residual-learner selection (`tab:ml-model-selection`), selected iterations (`tab:hyperparameters`) | `rf32` |
| `s02_bbm_selection` | `02_bbm_selection` | Pure-ML (BBM) selection and the overall performance table (`tab:overall-performance`) | `rf33` |
| `s03_core_results` | `03_core_results` | Data protocol record counts (`tab:benchmarks`), fitted physics scale (`tab:wbm-params`) | `rf36` |
| `s04_figures_3_4` | `04_figures_3_4` | Figures 3 and 4 (`fig:architecture-performance`, `fig:pred-actual`) | `rf41` |
| `s05_fuelcast_huber` | `05_fuelcast_huber` | No paper value; earlier FuelCast run read by `s06` as its comparison (not shipped, regenerated by a full rerun) | `rf42` |
| `s06_fuelcast_wind_and_wbm` | `06_fuelcast_wind_and_wbm` | FuelCast cross-vessel results (`tab:fuelcast-performance`, record counts in `tab:benchmarks`); exits with code 2 by design, see `reproduce/stages.json` | `rf43` |
| `s07_decision_uncertainty` | `07_decision_uncertainty` | Decision performance and predictive uncertainty (`tab:decision-results`, `tab:uncertainty-results`) | `rf49` |
| `s08_multigas_cii` | `08_multigas_cii` | Multi-gas emissions and CII (`tab:multigas-results`, `tab:cii-results`) | `rf50` |
| `s09_fig2_lambda` | `09_fig2_lambda` | Figure 2, shrinkage sensitivity (`fig:shrinkage-sensitivity`) | `rf52` |
| `s10_architecture_friedman_nemenyi` | `10_architecture_friedman_nemenyi` | Friedman and Nemenyi tests of the four architectures (`tab:friedman-nemenyi-tests`, `fig:nemenyi-pvalue-heatmaps`) | `rf54` |
| `s11_block_bootstrap` | `11_block_bootstrap` | Paired moving-block bootstrap of MAPE differences (`tab:block-bootstrap-mape`) | `rf55` |
| `s12_table6_selection_check` | `12_table6_selection_check` | Every candidate learner scored on all partitions after selection (`tab:mlp-sensitivity`, appendix) | `rf59` |
| `s13_mlp_architecture_sensitivity` | `13_mlp_architecture_sensitivity` | MLP hidden-layer sensitivity (`tab:mlp-sensitivity`, appendix) | `rf61` |

Shared modules, which write no results folder of their own:

| Module | Role | Original name |
|---|---|---|
| `common_rev.py` | Physics model, grey-box model wrappers, output writers and the results root (`VFM_RESULTS_ROOT`) | `common_rev.py` |
| `regret_core.py` | Decision-regret computations used by `s07` | `regret_core.py` |
| `ml_statistical_comparison.py` | Friedman and Nemenyi helpers used by `s10` | `rf17` |

The original names are those of the paper's revision rounds, where the scripts were numbered
in the order they were written; the paper and its response letters may refer to them.
